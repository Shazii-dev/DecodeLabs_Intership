# DecodeLabs Project 2 - Data Classification Pipeline

## Project Overview
Project 2 is a Python supervised learning pipeline using the Iris dataset and K-Nearest Neighbors (K=5). The script trains a model, evaluates accuracy, precision, F1 score, and prints a confusion matrix.

## Contents
- `Code/Project_2.py` - main classification script
- `Code/requirements.txt` - Python dependencies
- `AI P2.pdf` - project documentation/report

## How to Run
1. Create a Python environment
2. Install dependencies:
   ```bash
   pip install -r Code/requirements.txt
   ```
3. Run the script:
   ```bash
   python Code/Project_2.py
   ```
