# DecodeLabs Project 1 - Rule-Based AI Chatbot

## Project Overview
Project 1 is a rule-based Python chatbot called **Logic Engine**. It uses a dictionary of predefined user intents and returns deterministic responses. The code is designed to demonstrate control flow, input normalization, and basic AI logic without machine learning.

## Contents
- `Code/Project_1.py` - main chatbot script
- `AI P1.pdf` - project documentation/report

## How to Run
1. Open a terminal in `AI P1/Code`
2. Run `python Project_1.py`
3. Type messages like `hello`, `what is project 1`, or `exit` to quit
